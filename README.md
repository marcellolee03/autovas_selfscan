# Intelligent Patch Generator

**A complete solution for automated vulnerability assessment and intelligent patch generation.**

## Features
- **Automated Vulnerability Discovery**: Automatically identifies the localhost IP, creates the task in OpenVAS, and starts it.
- **Environment-Aware**: Incorporates computing environment details into the patch generation process.
- **Intelligent Data Processing**: Generates a detailed prompt containing vulnerability and computing environment information for maximum effectiveness.
- **AI-Driven Intelligent Remediation**: Generates customized patches using either the Google Gemini or Deepseek API.
- **Full Automation**: Completely automates the process, from detection to remediation.


### Prompt Examples Used

In the `prompt` directory of the repository, you can find the prompt used for generating the remediation patches. 
Note that the prompt was utilized as an f-string within the main application.

### Generated Patch Examples

The repository contains real-world examples of patches generated by this solution in the `Generated Scripts` directory.

## Prerequisites

- Docker Compose

## Installation

1. Clone the Repository:
```bash
git clone https://github.com/your-username/AutoVAS.git
cd AutoVAS
```

2. Run the setup script:
```bash
./setup-autovas.sh
```

## Usage
### Configuration

1. **Define API_KEY**: Edit line 6 of the 'src/main' file to include your API key:
  - For Google Gemini: Add your Google API key.
  - For Deepseek: Add your OpenRouter API key.

2. **Define API_URL**: Edit line 7 of the 'src/main' file to include the API URL:
  - For Google Gemini: The constant can be left empty.
  - For Deepseek: Set API_URL to "https://openrouter.ai/api/v1/chat/completions"
    

3. LLM Selection: Modify line 46 in 'src/main.py' based on the LLM you wish to use:
   **For Google Gemini::**
   ```python
   response = ask_LLM.ask_gemini(API_KEY, prompt)
   ```
   
   **For DeepSeek:**
   ```python
   response = ask_LLM.ask_deepseek(API_KEY, API_URL, prompt)
   ```


### Running AutoVAS

Execute the main application:
```bash
python src/main.py
```
